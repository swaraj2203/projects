A computer cannot store infinitely many possible values, the Real numbers.

A 'double' gives only a finite set of representable numbers.

IEEE 754 is the standard that specifies how floating-point numbers are represented and how floating-point arithmetic behaves.

IEEE 754 binary64 is usually called double.
It stores three pieces of information.

Sign : 1 bit
Exponent : 11 bits
Fraction : 52 bits

Therefore, 64 bits.
